# 岩田 快道 — Portfolio

就職活動向けのポートフォリオサイトです。

公開URL: https://kaikai-kitan.github.io/myportfolio/

## 構成

- `index.html`: プロフィール、スキル、活動、映像作品、連絡先

## ローカル確認

```sh
python3 -m http.server 8000
```

http://localhost:8000 を開いて確認できます。

## 公開

GitHub Pages は `main` ブランチのルートから公開します。
`index.html` や画像を更新して `main` に push すると公開サイトに反映されます。
